# 2025 E 题视觉通信协议

`2025-E-Vision/ff.py` 通过 MaixCAM UART1 发送目标误差，`2025-E-Car/driver/maixcam.c` 在 MSPM0 端逐字节解析。

## 串口参数

- 波特率：`115200`
- 数据位：8
- 停止位：1
- 校验位：无
- 字节序：坐标使用大端序

## 数据帧

每帧固定 9 字节：

| 偏移 | 字段 | 值或说明 |
| ---: | --- | --- |
| 0 | 帧头 1 | `0xFF` |
| 1 | 帧头 2 | `0xFE` |
| 2 | 控制字 | `0x55` |
| 3 | 数据长度 | `0x04` |
| 4 | X 高字节 | `X[15:8]` |
| 5 | X 低字节 | `X[7:0]` |
| 6 | Y 高字节 | `Y[15:8]` |
| 7 | Y 低字节 | `Y[7:0]` |
| 8 | 校验和 | 前 8 字节累加和的低 8 位 |

视觉端发送前执行：

```text
X = clamp(int(error_x) + 224, 0, 65535)
Y = clamp(int(error_y) + 224, 0, 65535)
```

MSPM0 端读取到的是加过 `224` 偏移的无符号数。控制代码通常通过 `get_maixcam_x() - 224` 和 `get_maixcam_y() - 224` 还原误差。

未检测到有效目标时，视觉端调用 `send_error_data(666, 666)`。因此 MSPM0 端以还原后的 `666` 作为丢失目标标记。

## 接线

| MaixCAM | MSPM0G3507 | 说明 |
| --- | --- | --- |
| A19 / UART1 TX | PA9 / UART1 RX | 视觉数据发送 |
| A18 / UART1 RX | PA8 / UART1 TX | 可选回传 |
| GND | GND | 必须共地 |

实际使用前请结合开发板原理图再次确认引脚电平和丝印。
